# Campus Marketplace AI

**AI-powered Student Marketplace Website**

## 1. Project Overview

Campus Marketplace AI là nền tảng Marketplace dành cho sinh viên Đại học Quốc gia TP.HCM, hỗ trợ mua bán sản phẩm học tập và các mặt hàng phục vụ đời sống sinh viên.

Dự án tích hợp các chức năng AI nhằm hỗ trợ tìm kiếm, gợi ý sản phẩm và tạo nội dung tin đăng.

## 2. Project Scope

Dự án được phát triển theo hai giai đoạn:

- **Phase 1 - Frontend:** Xây dựng giao diện website, điều hướng và mô phỏng các chức năng người dùng.
- **Phase 2 - Backend:** Xây dựng API, xử lý nghiệp vụ, quản lý dữ liệu và tích hợp với Frontend.

## 3. Main Features

- User Registration and Login
- Product Search and Filtering
- Product Listing Management
- Product Details
- Buyer-Seller Chat
- AI01 - AI Product Search Chatbot
- AI02 - AI Product Recommendation
- AI03 - AI Product Description Assistant
- User Ratings and Reporting
